# Наградной бот для Discord

Бот для ведения «наградных книжек» на сервере: звания, специализации, медали.

## Возможности

- **Заполнение формы звания** — команда `/звание` открывает модальную форму.
- **Наградная книжка** — команда `/книжка` показывает свои звания и медали
  одной хронологической лентой.
- **Выдача медалей админом** — команда `/медаль` выдает медаль игроку.
- **Защита от дубликатов** — одинаковая медаль/звание у одного игрока повторно не выдаётся.
- **Логирование** — все выдачи можно отправлять в отдельный канал.

## Установка

```bash
cd award_bot
pip install discord.py
```

## Настройка

1. Создай бота на https://discord.com/developers/applications и скопируй токен.
2. Открой `config.py` и впиши токен в `BOT_TOKEN`.
3. Укажи `GUILD_ID` (ID своего сервера), чтобы команды появились сразу.
4. (Опционально) укажи `ADMIN_ROLE_NAME` и `LOG_CHANNEL_ID`.

### Права бота (Invite)

При приглашении бота на сервер включи **Administrator** или как минимум:
- `Send Messages`
- `Embed Links`
- `Use Slash Commands`

Включи в настройках бота в панели разработчика:
- `SERVER MEMBERS INTENT` (для upствия участников)

## Запуск

```bash
python bot.py
```

## Команды

| Команда | Кто может | Описание |
|---|---|---|
| `/звание` | все | Открыть форму, сохранить звание/специализацию |
| `/книжка` | все | Показать свою наградную книжку |
| `/медаль <игрок> <название> [причина]` | админ | Выдать медаль (с защитой от дублей) |
| `/забрать <ид>` | админ | Удалить медаль по id |

## Схема данных

Хранится в `data/awards.db` (SQLite).

- **ranks** — звания пользователя (уникальны для каждого пользователя).
- **medals** — медали, с указанием кто выдал (`awarded_by`).

БД создаётся автоматически при первом запуске.
